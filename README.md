## 🧾 Descrição Geral

Aplicativo com 3 telas para registrar pedidos na lanchonete **Lanche Fácil**. O cliente insere seu **nome** por meio de um campo `TextInputLayout` e seleciona um dos lanches disponíveis:  
**Pizza, Cachorro-Quente, Batata Frita ou Pastel**.  
Após o envio, o aplicativo exibe um resumo com o nome do cliente e o lanche escolhido, junto a uma imagem ilustrativa.

## 🚀 Funcionalidades

- Tela de boas-vindas com logomarca e botão para iniciar pedido;
- Formulário com campo para digitar o nome (`TextInputLayout`);
- Botões para selecionar o tipo de lanche (Pizza, Cachorro-Quente, Batata Frita, Pastel);
- Tela de resumo com nome e lanche escolhidos;
- Imagem decorativa de pedido concluído;
- Botão para voltar à tela inicial e realizar novos pedidos.

## 💡 Processo de Desenvolvimento

Desenvolvido com base no fluxo de 3 `Activities`, utilizando passagem de dados com `Intent` e `Bundle`, e componentes visuais como `TextInputLayout`, `Button`, `TextView` e `ImageView`.  
Foco especial foi dado à navegação fluida entre telas, clareza da interface e retorno visual agradável ao usuário.
